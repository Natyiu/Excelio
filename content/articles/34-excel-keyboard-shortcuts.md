# 40 Excel Keyboard Shortcuts Worth Learning (Windows and Mac)

Shortcut lists with 200 entries don't help anyone. These are the ones that matter most for everyday work, grouped by task. Learn one group a week and you'll be noticeably faster within a month.

> 💡 **Want to practise as you read?** Open a free live spreadsheet on [Excelio](https://excelio.com/learn-excel) and try every step yourself.

---

## 1. Move around fast

| Action | Windows | Mac |
|---|---|---|
| Jump to edge of data | Ctrl + Arrow | Cmd + Arrow |
| Go to A1 | Ctrl + Home | Fn + Ctrl + ← |
| Go to last used cell | Ctrl + End | Fn + Ctrl + → |
| Next / previous sheet | Ctrl + PgDn / PgUp | Fn + Ctrl + ↓ / ↑ |
| Go To (any cell or name) | Ctrl + G or F5 | Ctrl + G |

**Ctrl + Arrow** is the single most valuable shortcut in Excel. On a 10,000-row sheet, it takes you to the bottom in one keystroke.

---

## 2. Select ranges

| Action | Windows | Mac |
|---|---|---|
| Extend selection to edge of data | Ctrl + Shift + Arrow | Cmd + Shift + Arrow |
| Select whole column | Ctrl + Space | Ctrl + Space |
| Select whole row | Shift + Space | Shift + Space |
| Select current region / all | Ctrl + A | Cmd + A |
| Extend selection by one cell | Shift + Arrow | Shift + Arrow |

Click the top of a column, then **Ctrl + Shift + ↓** to select every row of data instantly.

## 3. Edit

| Action | Windows | Mac |
|---|---|---|
| Edit active cell | F2 | Ctrl + U |
| Fill down | Ctrl + D | Cmd + D |
| Fill right | Ctrl + R | Cmd + R |
| Enter in all selected cells | Ctrl + Enter | Ctrl + Enter |
| New line inside a cell | Alt + Enter | Option + Enter |
| Undo / Redo | Ctrl + Z / Ctrl + Y | Cmd + Z / Cmd + Y |
| Find & Replace | Ctrl + H | Ctrl + H |
| Insert today's date | Ctrl + ; | Ctrl + ; |
| Flash Fill | Ctrl + E | Ctrl + E |

**Ctrl + Enter** is underrated: select 50 cells, type a value or formula once, press Ctrl + Enter, and every cell is filled.

## 6. Formulas and data

| Action | Windows | Mac |
|---|---|---|
| AutoSum | Alt + = | Cmd + Shift + T |
| Cycle $ references | F4 | Cmd + T |
| Show all formulas | Ctrl + ` | Ctrl + ` |
| Create a Table | Ctrl + T | Cmd + T |
| Toggle filters | Ctrl + Shift + L | Cmd + Shift + F |
| Recalculate | F9 | Fn + F9 |
| Evaluate part of a formula (in edit mode) | F9 | Fn + F9 |

On Mac, Cmd + T cycles `$` references while you're editing a formula and creates a Table otherwise.

---

## 7. Ribbon key tips (Windows)

Press **Alt** and letters appear on the ribbon. Every command is reachable by keyboard. Some favourites:

- **Alt, H, O, I**: AutoFit column width
- **Alt, A, V, V**: Data Validation
- **Alt, N, V**: Insert PivotTable
- **Alt, W, F, F**: Freeze Panes

You don't hold the keys down. Press them one after another.

---

## How to actually remember them

Reading a list doesn't build muscle memory. **Using** them does. Three rules:

1. **Pick three** shortcuts per week, not thirty.
2. **Force yourself**: when you reach for the mouse to do one of them, stop and use the keys.
3. **Practise in short bursts**: a few minutes of deliberate drills beats a one-hour read.
